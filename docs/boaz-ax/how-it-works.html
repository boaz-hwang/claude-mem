claude-mem 동작 원리

포크 boaz-hwang/claude-mem · 기준 커밋 a046a6a9f(upstream v16.1.x) · 2026-11-24 코드 조사 · 경로는 저장소 루트 기준. 근거를 직접 읽지 못한 항목은 (추정)으로 표시했습니다.

한 줄 요약: Claude Code 훅이 세션 중 일어난 일을 로컬 worker에 넘기면, worker가 Haiku로 압축한 관찰(observation)을 만들어 SQLite·FTS5·Chroma에 저장합니다. 다음 세션이 시작될 때 같은 프로젝트의 최근 관찰 50개를 맥락으로 넣어 줍니다.
  1. 수집 — 도구를 쓸 때마다 PostToolUse 훅이 이벤트를 spool 파일에 쌓습니다.
  2. 압축 — worker가 Claude Agent SDK query()로 관찰을 생성하고, Stop 때 세션 요약을 만듭니다.
  3. 저장·색인 — ~/.claude-mem/claude-mem.db(SQLite WAL) + FTS5 + Chroma(벡터)에 저장합니다.
  4. 주입 — SessionStart 훅이 같은 프로젝트의 최근 관찰과 요약을 타임라인으로 렌더링해 넣습니다.
  5. 검색 — MCP 도구 search → timeline → get_observations가 worker HTTP API를 호출합니다.

3. 쓰기 경로 자세히

관찰 1건이 만들어지기까지

  1. PostToolUse 훅 → observationHandler가 이벤트를 <data>/state/hook-spool에 씁니다. observation.ts:30-34,148
  2. 원격 worker를 쓰면 /api/spool/ingest로 보내고, 로컬이면 drain이 가져갑니다. HookSpoolRoutes.ts:23
  3. 원문 도구 입출력은 tool_uses에 저장합니다. 필드당 64KB에서 잘립니다. tool-uses.ts:35,240-241
  4. 프롬프트를 조립합니다(init·observation·summary 3종, 모드 템플릿 plugin/modes/*.json). 필드당 16,000자까지 넣고, 넘으면 앞 60%와 끝을 남깁니다. src/sdk/prompts.ts:121,185,400,477
  5. 기본 provider는 claude, model은 haiku입니다. SettingsDefaultsManager.ts:551,587
  6. 응답을 파싱해 observations에 저장하고 Chroma에 동기화합니다. FTS5는 SQLite 안에서 색인합니다. ResponseProcessor.ts:1138 · SessionSearch.ts:286

7. History 계층 요구사항과의 차이

요구사항 출처: ax-boaz-docs/4layer-system.md 9절 Agent Session DB(일부 항목은 제안 단계).

요구현재상태바꿔야 할 지점
R1 서버가 사내망 신원으로 사용자 ID 주입팀 API 키뿐이고 userId는 항상 null. projectId는 클라이언트가 보냄신규인증 모드 network-identity(Tailscale whois → GitHub ID), 모든 테이블에 user_id
R2 CRUD 속도, SQLite 우선SQLite WAL 사용. 서버용 SQLite 스키마도 있음있음벤치마크만 하면 됨
R3 프로젝트에 속하지 않고 Beads와 느슨히 연결모든 테이블에 project가 필수신규고정 "global" 프로젝트 하나 + metadata JSONB에 cwd·git·Beads ID 신호. ID 추출기 신규
R4 공개 기본·비공개 지정·전파 차단본문의 <private> 태그 제거뿐신규visibility 컬럼, 비공개를 읽으면 자동 승격, wiki-update용 public 전용 조회 경로
R5 허용 목록 수집차단 목록(CLAUDE_MEM_EXCLUDED_PROJECTS)만 있음일부should-track-project.ts에 허용 목록 분기 + 서버에서 재검사
R6 원문 JSONL을 자르지 않고 줄 단위로 보관64KB·16k 상한이 있고 줄 주소 없음. watcher는 있음신규transcript_lines(session_id, line_no, raw) + /claude-sessions/<id>.jsonl 원문 제공
R7 개인 claude-mem과 공존데이터 디렉터리·포트·claude-mem 실행 명령·플러그인 이름·MCP 이름이 겹침조치 필요개발 중에는 플러그인으로 설치하지 않고 CLAUDE_MEM_DATA_DIR와 포트를 분리해 별도 프로세스로 실행. npm run dev 금지(설치된 플러그인을 건드림)
